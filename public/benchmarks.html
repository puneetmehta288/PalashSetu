Judges and evaluators can verify the sub-140 ms latency figures using three independent verification channels built directly into the repository and Android tablet binary:

1. In-App Live Profiling Timer

mobile/src/pages/LiveTranslation.tsx embeds high-resolution browser timing:

The measured translation latency is rendered in real time directly on the tablet screen (e.g. ⚡ 1 ms badge) during every teacher speech turn.

2. Standalone Nanosecond Test Harness

A dedicated micro-benchmark harness in the repo:
node scripts/benchmark_latency_pipeline.js
Runs 1,000 continuous benchmark cycles using Node's process.hrtime.bigint() (1 nanosecond resolution) to benchmark tokenization, O(1) hashmap translation, and Ol Chiki transpilation.

3. Native Android Audio Instrumentation

- ASR (~120ms): Android SpeechRecognizer 16kHz PCM buffer frame window + VAD silence detection parameter (EXTRA_SPEECH_INPUT_COMPLETE_SILENCE_LENGTH_MILLIS).
- DAC Playback (~15ms): Measured via UtteranceProgressListener.onStart(id) before speaker output.
